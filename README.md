## ✨ Features & Highlights

### 🏠 Home Page (`index.html`)
- **Embedded Video Tutorial**: Features a full Front-End Web Development video tutorial in Tamil.
- **Detailed Timestamps**: Complete navigation guide for video topics (HTML, CSS, Flexbox, JS, E-Commerce Project).
- **Tech Stack Breakdown Table**: A structured comparison table explaining the core roles of HTML, CSS, and JavaScript.
- **Quick Links**: Direct access to registration, LinkedIn, and email support.

### 📝 Course Registration Page (`register.html`)
- **Interactive Registration Form**: Comprehensive form collect user details.
- **Input Fields**: Name, Age, Gender selection (Radio buttons), Email, and Status dropdown.
- **Resume Upload**: File input field for candidates to upload their CV/Resume.
- **Form Controls**: Built-in Reset and Submit actions.
